# 🌾 AgriSupply Fertilizer Management System

AgriSupply is a full-stack web application designed to simplify fertilizer inventory and management for agricultural suppliers. The system provides an organized platform to manage fertilizers, users, and customer feedback while ensuring efficient database management through a modern web stack.

---

## 🚀 Features

- 👤 User Registration & Authentication
- 🌱 Fertilizer Inventory Management
- 📝 Customer Feedback System
- 📊 Structured Database Management
- ⚡ Responsive and User-Friendly Interface
- 🔒 Secure Backend Architecture

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Aswin911/AgriSupply-Fertilizer-management-System-.git
```

```bash
cd AgriSupply-Fertilizer-management-System-
```

---

### Install Frontend Dependencies

```bash
cd client
npm install
```

---

### Install Backend Dependencies

```bash
cd ../server
npm install
```

---

## 🔧 Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=agrisupply
```

---

## ▶️ Running the Project

### Start Backend

```bash
npm start
```

or

```bash
npm run dev
```

---

### Start Frontend

```bash
npm run dev
```
